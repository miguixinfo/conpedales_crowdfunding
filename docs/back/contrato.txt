🔥 **Conpedales** suena muy bien. Corto, fácil de recordar y muy alineado con el proyecto. La idea tiene pinta de quedar brutal si el backend está bien pensado desde el principio. Vamos a estructurarlo **como si fuera el diseño técnico inicial del backend**.

Stack confirmado:

* Backend → Spring Boot
* Build → Apache Maven
* Pagos → Stripe
* Imágenes → Cloudflare R2
* Front → React / React Native (admin)

---

# 🧠 1. Dominio del sistema (lo más importante)

Tu dominio real tiene **6 entidades principales**.

```
Stage (etapa)
RouteSegment (rutita)
Photo
Donation
Comment
Stats (calculado)
```

Relaciones:

```
Stage
 ├── RouteSegment (1:N)
 ├── Photo (1:N)
 └── coordenadas inicio/fin

RouteSegment
 └── Photo (1:N)

Donation
 └── Comment (1:1 opcional)
```

# 📊 3. Stats globales

Esto **NO lo guardaría**.

Se calcula:

```
SUM(stage.km)
SUM(stage.elevation_gain)
COUNT(stage)
SUM(donation.amount)
COUNT(donation)
```

Endpoint:

```
GET /stats
```

Response:

```json
{
  "totalKm": 2345,
  "totalElevation": 32100,
  "totalStages": 27,
  "totalDonations": 310,
  "totalFunded": 2345
}
```

💡 Así el frontend puede hacer:

```
2345€ = 2345km financiados
```

# 💳 5. Flujo de donación

Flujo con Stripe:

```
frontend
   ↓
POST /donations/checkout

backend
   ↓
crear checkout session stripe
   ↓
redirigir usuario
   ↓
pago completado
   ↓
webhook stripe
   ↓
guardar donation
   ↓
guardar comment
```

Endpoints:

### crear checkout

```
POST /donations/checkout
```

request

```json
{
  "amount": 10,
  "name": "Carlos",
  "comment": "Mucho ánimo chavales!"
}
```

---

### webhook stripe

```
POST /stripe/webhook
```

Se verifica firma y se guarda.

---

### feed de comentarios

```
GET /donations/feed
```

response

```json
[
  {
    "name": "Carlos",
    "amount": 10,
    "comment": "Mucho ánimo chavales",
    "date": "2026-05-03"
  }
]
```

# 📸 6. Subida de fotos

Con Cloudflare R2.

Backend **no recibe la imagen**.

Flujo moderno:

```
admin panel
 ↓
GET /upload-url
 ↓
backend genera presigned URL
 ↓
frontend sube directo a R2
 ↓
guarda URL en /photos
```

Endpoints:

```
POST /photos
GET /photos/stage/{id}
```
